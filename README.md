## Installation
If you have an apple laptop, follow option 3
1. For Firefox users, download the .XPI file and run it.
2. For Chrome users, download the .CRX file and run it.
3. For Mac users:
    1. Download the .ZIP file
    2. Extract it
    3. For Chrome, use developer mode:
        1. Open Chrome and type `chrome://extensions/` into the URL bar.
        2. Toggle the **Developer mode** switch in the top-right corner.
        3. Click the **Load unpacked** button in the top-left corner.
        4. Select your extracted extension folder to install it.
## How it works
The script will find the question text and use it to identify the question. It will remember any answer you give to it, as well as any answers saved to the database. After each question, your answer will be send to the database for other people to use. If you find a question someone has already answered, the answer will be given in the bottom left. If you are on audio only mode, you can still see the question text in the bottom left.
